## Run Locally

### Prerequisites
- Node.js v18+
- npm

### Setup

1. Clone the repository

```bash
git clone https://github.com/HanKwan/Movie-app-react
cd movie-app
```

2. Install dependencies

```bash
npm install
```

3. Create a `.env` file in the project root

```env
VITE_TMDB_API_KEY=your_api_key_here
```

4. Start the development server

```bash
npm run dev
```
